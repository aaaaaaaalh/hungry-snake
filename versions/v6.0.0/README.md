# 贪吃蛇游戏 🐍

一个纯前端、单文件的贪吃蛇小游戏，支持多账号注册登录、背景音乐、音效、MP3 音乐库、限时奖励、关卡系统和虚拟摇杆。每个账号可自定义头像和昵称、选择电脑/手机设备，数据完全独立。无需安装任何依赖，双击 `index.html` 即可游玩。

## 运行方式

直接双击 `snake-game/index.html`，或用浏览器打开即可。

## 声音与音效

- **背景音乐**：点击开始后自动播放轻快旋律，暂停时停止、继续时恢复
- **音效**：吃食物有清脆提示音（音调随得分升高）、死亡有低沉音效、通关有庆祝琶音
- **音量调节**：页面右下角音量滑杆，拖动自由调整 0-100%；图标随音量变化（🔇 / 🔉 / 🔊），偏好自动记忆

## 玩法（v5.0）

- **地图**：24×24 网格，比之前更大
- **限时奖励**：游戏过程中会随机出现金色星星 ★，持续 8 秒后消失，吃到 +20 分并让蛇 **+2 体长**；奖励会反复随机出现
- 普通食物仍是 +10 分、+1 体长

## 设备与摇杆（v5.0）

- 登录 / 注册 / 游客进入时会询问「电脑玩家」还是「手机玩家」，选择自动记忆（账号绑定资料，游客单独保存）
- **手机玩家**：屏幕左下角出现虚拟摇杆，拖动控制方向，松手自动回中；原滑屏控制仍可用
- **电脑玩家**：不显示摇杆，键盘方向键 / WASD 操作不变


## 关卡系统（v6.0）

- **关卡显示框**：得分栏中间显示当前关卡
- **100 分升级提示**：达到 100 分时弹出提示框，可选择「进入关卡 2」或「继续游玩」
- **进入关卡 2**：棋盘左下方生成一堵 L 形墙（竖墙 + 底边横墙），蛇碰到墙立即结束游戏；分数延续不清零
- **继续游玩**：停留在关卡 1，无墙
- 每局默认从关卡 1 开始，死亡或重新开始后回到关卡 1；食物与限时奖励不会生成在墙上

## 新界面布局（v6.0）

- 右上角：🎵 音乐库按钮（左）+ 档案大按钮（右，显示头像和昵称）
- 档案面板新增「我的账号 · 历史最高成绩」列表：显示本设备创建的所有账号和各自最高分
- 左下角：操作提示文本框（点击标题可折叠收起）
- 右下角：音量滑杆
## 音乐库（v4.0）

- **打开**：右上角 🎵 按钮
- **内置**：默认背景音乐，浏览器实时合成，无需文件
- **公共库**：所有账号共享，上传后大家都能用；删除仅限上传者本人
- **私人库**：仅当前账号可见可用，上传后只属于自己，换账号看不到
- **选用**：点击曲目右侧「选用」即作为游戏背景音乐，选择自动记忆
- **试听**：点击 ▶ 先试听，再决定是否选用
- 单首音乐不超过 20MB，推荐 MP3 格式（也支持其他常见音频格式）

> 说明：音乐文件保存在浏览器本地（IndexedDB）。公共库在同一浏览器所有账号间共享，私人库仅当前账号可见；数据仅存于本机，跨设备共享需接入服务器（可后续扩展）。

## 账号系统

- **注册**：点击右上角头像 → 注册标签页，填写用户名、昵称、密码，挑选头像（预设表情或自定义表情 + 背景色）
- **登录**：注册过的账号用用户名 + 密码登录，自动恢复该账号的数据
- **游客模式**：不想注册也能玩，点「先随便玩玩」即可，数据单独保存
- **数据独立**：每个账号的最高分、总局数、总得分互不影响
- **编辑资料**：游戏中点击右上角头像，可修改昵称、头像、查看战绩、退出登录

> 说明：账号数据保存在浏览器本地（localStorage），密码加盐哈希存储。账号仅在本机浏览器内有效，如需跨设备保存需接入服务器（可后续扩展）。

## 玩法与操作

- **方向控制**：方向键 `↑ ↓ ← →` 或 `W A S D`（手机用摇杆或滑动）
- **暂停 / 继续**：`空格`
- **重新开始**：`R` 或点击「重新开始」按钮
- **操作提示**：左下角文本框随时可查，点击「🎮 操作提示」标题可折叠收起

## 功能特性

- 24×24 网格，普通食物得分 +10/个
- 每吃一个食物速度略微提升（越来越快，有下限）
- 100 分解锁关卡 2，撞墙即死的新挑战
- 最高分、总局数、总得分按账号分别保存
- 自动暂停：切到其他标签页时游戏自动暂停，防止误死
- 响应式布局，支持手机横竖屏游玩
