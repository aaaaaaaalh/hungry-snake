# 贪吃蛇游戏 🐍

一个纯前端、单文件的贪吃蛇小游戏，无需安装任何依赖，双击 `index.html` 即可在浏览器中游玩。

## 运行方式

直接双击 `snake-game/index.html`，或用浏览器打开即可。

## 玩法与操作

- **方向控制**：方向键 `↑ ↓ ← →` 或 `W A S D`
- **暂停 / 继续**：`空格`
- **重新开始**：`R` 或点击「重新开始」按钮
- **手机触屏**：在游戏画面上滑动即可控制方向

## 功能特性

- 经典 20×20 网格，得分 +10/个
- 每吃一个食物速度略微提升（越来越快，有下限）
- 最高分通过 `localStorage` 本地保存
- 自动暂停：切到其他标签页时游戏自动暂停，防止误死
- 响应式布局，支持手机横竖屏游玩
